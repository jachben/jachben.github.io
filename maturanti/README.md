# Fotky maturantů

Sem nahraj portréty, každou třídu do své složky:

- `4FP/` – fotky třídy 4FP
- `4G/` – fotky třídy 4G

Jak nahrát: otevři složku třídy, klikni na **Add file → Upload files**,
přetáhni fotky a dej **Commit changes**.

Fotky se pak zmenší a objeví se na stránce ve Vzkazech u dané třídy.
